# HANDOFF — ephemeral by design

**This is not a source of truth.** The durable truth lives in:

- **[README.md](README.md)** — project-facing: what Audiology is, features, architecture,
  the vision roadmap.
- **[CLAUDE.md](CLAUDE.md)** — agent-facing: invariants, conventions, gotchas, current
  status, the Tonality bridge mechanics, and the open engineering threads.

A `HANDOFF*.md` exists only to **pass work between agents at a specific point in the dev
process** — a transient note for one handoff. When you spawn one, keep it scoped to that
moment, and **delete it once consumed**. Anything worth keeping belongs back in README or
CLAUDE, not here.

_No handoff is currently in progress._
